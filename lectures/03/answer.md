## 演習

- 第1回（素のLLM）とエージェントの回答の違い：
  - 第1回の `app.ask` は「基礎・標準・発展の3段階」と、一般論を講座の決まりのように答えていた
  - エージェントは「基礎（講義内容の確認）・実装（自分でコードを書く）・発展（調査や試行）」「どれか1つで完了」「原則として採点しない」と答え、用語集の `homework-levels` と一致した。最後に「関連する回：第1回」も付いていた（このときは `--trace` を付けていないので、検索したかは出力からは確かめていない）
- `--trace` で見えたツール呼び出し（ツール名と引数）：
  - 「LoRAとQLoRAの違いは？」：`search_glossary({'query': 'LoRA'})` と `search_glossary({'query': 'QLoRA'})`。docstring の「用語を1つだけ入れる」のとおり、2語を別々に検索していた。回答は用語集の定義（低ランク行列だけを学習／4ビットに量子化してから LoRA）に沿っていた
  - 「第2回の内容から確認問題を1問出して」：`make_quiz({'lecture': 2})`。「教師ありファインチューニング（SFT）」の問題を受け取り、答えは見せずに問題だけを出題した
- 1つの質問での LLM 呼び出し回数（`requests`）：
  - LoRA/QLoRA：`requests=2, tool_calls=2`（入力 1468 / 出力 199 トークン）。1回目で2つの検索をまとめて依頼し、2回目で回答を作っている
  - 確認問題：`requests=2, tool_calls=1`（入力 1001 / 出力 66 トークン）
- 追加したツールと、docstring に書いた説明：
  - `make_quiz(lecture: int) -> str`（`app/tools.py`）。用語集から指定した回の用語を `random.choice` で1つ選び、`{"question": "「○○」の意味は？", "answer": 定義}` を JSON で返す。該当する用語がない回（例：第0回）では、問題を作れる回の一覧を返す
  - docstring：「指定した回の用語から確認問題を1問作って返す。『第2回の確認問題を出して』のように、回を指定して問題（クイズ・小テスト・復習問題）を求められたときに使う。答えはすぐに見せず、まず問題だけを出題すること」
  - `app/agent.py` で `agent.tool_plain(tools.make_quiz)` と登録し、`--list-tools` に表示されることを確認。`uv run pytest -q` は 17 passed
